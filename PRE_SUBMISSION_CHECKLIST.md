## Phase 5: Post-Submission

### Immediately After Submission

- [ ] **Save confirmation email**
- [ ] **Note manuscript ID** (e.g., EMSE-D-25-XXXXX)
- [ ] **Update README.md** with "Under Review" status
- [ ] **Tweet/announce** submission (optional)

### During Review (3-6 months)

- [ ] **Respond to editor inquiries** promptly
- [ ] **Check status** in Editorial Manager periodically
- [ ] **Prepare for revisions** (expected after first review)
  - Reviews typically request major revisions
  - Budget 2-4 weeks for revision work
  - May need additional experiments/analyses

### If Major Revisions Requested

- [ ] **Read reviews carefully** (don't respond emotionally)
- [ ] **Create revision plan** addressing each comment
- [ ] **Revise manuscript** systematically
- [ ] **Write point-by-point response** to reviewers
  - Quote each comment
  - Explain how addressed
  - Reference specific changes (line numbers, sections)
- [ ] **Resubmit** within deadline (typically 3 months)

### If Rejected

- [ ] **Don't despair** (happens to everyone)
- [ ] **Learn from reviews** (often valuable feedback)
- [ ] **Revise and resubmit** to alternative venue
  - Option: ICSE 2026 (conference, more condensed)
  - Option: FSE 2026 (conference)
  - Option: MSR 2026 (data showcase track)
  - Option: Another journal (TSE, JSS)

### If Accepted 🎉

- [ ] **Celebrate!** 🎊
- [ ] **Prepare camera-ready version**
- [ ] **Sign copyright transfer** (if required)
- [ ] **Pay open access fees** (if choosing open access)
- [ ] **Update GitHub repo** with citation
- [ ] **Update README** with "Published in EMSE" badge
- [ ] **Share widely**:
  - Twitter/social media
  - Mailing lists (e.g., SEWORLD)
  - Department seminar
  - Conference workshops
